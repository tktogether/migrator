# 发布文案

本目录收录对外发布使用的文案草案，与产品文档分开维护。

| 文件 | 用途 |
|---|---|
| [project-intro.md](project-intro.md) | 项目简介，含长版与短版，可用于仓库描述、页面介绍或邮件 |
| [README-first-screen.md](README-first-screen.md) | 根 `README.md` 首屏草案 |
| [RELEASE-NOTES.md](RELEASE-NOTES.md) | 发布说明 |
| [ANNOUNCEMENT.md](ANNOUNCEMENT.md) | 对外公告稿 |

使用约定：

- 版本号以 `git describe` 与 `VERSION` 文件为准；
- 文案不粘贴测试日志、真实 IP、序列号或内部主机记录；
- 发布前应核对支持范围与已知限制；
- 仓库地址、发布物地址与联系方式由部署方填写，本目录不内置。
